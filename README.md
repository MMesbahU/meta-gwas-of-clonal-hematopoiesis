# Genomic and phenomic landscape of clonal hematopoiesis in over a million ancestrally diverse participants

This repository contains codes used in the paper (cite)  


## 1. [**CHIP and mCA calling**](https://github.com/MMesbahU/CHIP_metaAnalysis/tree/main/01.CHIP_n_mCA)
1.1. **Clonal hematopoiesis of indeterminate potential (CHIP)** calling was done using the pipeline described in [Bick,  et  al. 2021](https://www.nature.com/articles/s41586-020-2819-2)  (Terra workflow:https://app.terra.bio/#workspaces/terra-outreach/CHIP-Detection-Mutect2)

1.2. **Mosaic Chromosomal Alterations (mCA)** were identified using the [MoChA software](https://github.com/freeseek/mocha).    

## 2. [**GWAS**](https://github.com/MMesbahU/CHIP_metaAnalysis/tree/main/02.GWAS)
Genome-wide association analyses for CHIP (and top CHIP genes) were performed using [REGENIE](https://rgcgithub.github.io/regenie/) software. 


## 3. [**Meta-Analysis**](https://github.com/MMesbahU/CHIP_metaAnalysis/tree/main/03.Meta-Analysis)

Meta-analysis of CHIP GWAS was perfomed using [GWAMA software](https://manpages.ubuntu.com/manpages/xenial/man1/GWAMA.1.html)

## 4. [**SNP heritability**](https://github.com/MMesbahU/CHIP_metaAnalysis/tree/main/04.SNP_heritability)
SumHer function of [LDAK](https://dougspeed.com/sumher/) software was used for estimating SNP-based heritability
